## The five things to get first

If the client can only answer a handful before we start, these five unblock the most:

1. **A1** — logo, or permission to set a wordmark *(blocks every page)*
2. **A4** — palette approval *(blocks every page)*
3. **B1 + B2** — founding story and who runs it *(blocks About, which is the second-most-visited page on a site like this)*
4. **C3** — what the Sangha page is *(one sentence; otherwise we drop the route)*
5. **B5** — how many people are actually in the community *(sets the scale of everything)*

Everything else can proceed with samples.
